Viral Lab — Windows 使用说明

1. 解压整个 ZIP 到普通文件夹，不要在压缩包内部直接运行。
2. 双击“启动Windows.cmd”。建议 Windows 10 / 11。
3. 首次运行会通过 Windows winget 安装 uv 和 FFmpeg，再安装 Python 与程序依赖。
   需要联网；Windows 如显示安装授权，请按提示确认。安装可能需要几分钟。
4. 准备完成后浏览器会自动打开工作台。保留黑色终端窗口，关闭窗口会停止工具。
5. 点击“上传本地视频”，选择 MP4，在新页面设置截取时间、画幅、速度、叠加文字等。
6. 点击“下载并生成二剪视频”，成功后预览并下载成片。

下次使用仍然双击“启动Windows.cmd”，已安装的依赖会复用。
视频和任务保存在程序文件夹的 data 中；不要删除，除非你想清除所有本地数据。

平台采集：点击“采集视频”粘贴 TikTok / 抖音分享链接。
自动采集：进入“自动采集”添加链接，启用达标自动二剪。
在线抓取可能要求浏览器 cookies，或被平台限制；不能保证匿名访问成功。
本地上传和二剪不依赖平台登录，也不需要 AI key。

此包是启动脚本 + 程序源码，不是无需安装的 EXE。
Windows 启动脚本未在真实 Windows 机器上测试；若启动失败，请把终端错误文字发来。

若提示缺少 winget：从 Microsoft Store 安装或更新“应用安装程序”，再双击启动。
