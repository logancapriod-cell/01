# Viral Lab · 爆款视频采集与二剪工具

一个中文网页工作台：采集 TikTok / 抖音视频元数据，计算参考评分，下载原片并用 FFmpeg 生成二剪 MP4。也可以上传本地原片、生成辅助创作脚本和分镜。

## Windows 使用（推荐从这里开始）

解压 `ViralLab-Windows.zip`，双击 `启动Windows.cmd`。首次运行通过 Windows winget 安装 uv 与 FFmpeg，并准备 Python 3.12 和锁定的依赖；随后浏览器自动打开工作台。下次仍双击同一个文件即可。

保留启动窗口，关闭窗口会停止工具。程序运行于自己的电脑，默认仅监听本机；不会把本地上传的视频自动发到 GitHub。

先点击「上传本地视频」，选择原片，设置截取时间、画幅、速度和文字，再点击「下载并生成二剪视频」。结果在工作台内预览、下载，原片保留。平台下载是另外的流程，需要平台允许访问。

如果缺少 winget，请在 Microsoft Store 安装或更新「应用安装程序」。Windows PowerShell 脚本使用 UTF-8 BOM；FFmpeg 中文字体自动尝试微软雅黑等系统字体。平台登录可在左下角「本地工作台」中读取 Edge / Chrome / Firefox 默认配置，或选择 Netscape 格式 cookies.txt。只保存抖音和 TikTok cookies，文件保存在忽略的 `data/private`，重启后恢复，可在页面清除。Chrome / Edge 加密保护可能阻止读取，Firefox 或自行导出的文件是备用方式。此入口只在本机启动模式启用并限制本机来源。配置成功仍不能保证平台允许采集。详情见「先读我.txt」。Windows 启动脚本尚未经过真实 Windows 实机验证，安装或启动异常请保留窗口错误文字。

## 云环境运行

云环境工作目录为 `/workspace/01`，使用现有 checkout，不需要新建 Git worktree。依赖 Python 3.12、uv、FFmpeg / FFprobe（带 libx264 和 drawtext）、中文字体 Noto Sans CJK。

```bash
cd /workspace/01
bash scripts/setup.sh
bash scripts/start.sh
```

服务监听 8000 端口，可用 `PORT` 调整。页面入口是 `/`，健康检查 `/api/health`，接口说明 `/docs`。这是单用户开发工具，尚未实现账号登录；开放到公网前需要在网关配置认证。请只运行 **一个 Uvicorn worker / 一个应用实例**，避免定时采集重复执行。

## 使用流程

1. 在「发现爆款」点击「采集视频」，粘贴分享链接或分享文案。或者点击「导入 JSON」，导入你已有的数据。
2. 在视频卡片点击「下载 / 二剪」。支持截取时间范围、9:16 / 1:1 / 16:9、补边或居中裁切、0.5–2 倍速、固定文字叠加、静音。
3. 点击「下载并生成二剪视频」。没有原片时先下载；已有上传或下载的原片时复用。任务成功后可直接预览并下载 MP4，原片保留。
4. 需要自动流程时，在「自动采集」添加采集源，勾选「评分达标后，自动下载并二次剪辑」，设置分数、截取秒数、速度和文字。服务运行时每 10 秒检查到期采集源；按设置频率更新视频、评分，自动处理达标且未成功二剪的视频。自动输出 9:16、保留全画面和声音。同一视频成功处理一次后不再重复。
5. 「任务记录」展示排队、执行中、成功或具体失败原因，并提供下载入口。采集成功不代表其后下载、剪辑成功，它们是独立任务。

视频最长 10 分钟、最大 300 MB；每次账号采集最多 20 条。二剪是片段处理和转码，不自动发布、不提供去水印功能。固定叠加文字不等于语音识别字幕。请使用自己拥有或获授权的素材。

## 平台支持与当前限制

| 平台 | 支持输入 | 限制 |
| --- | --- | --- |
| TikTok | 视频链接、分享链接、公开账号主页 | 依赖 yt-dlp 适配器、平台网络和登录状态 |
| 抖音 | 视频链接、分享链接 | 当前不支持账号主页、官方全站热榜 |
| 本地 | MP4 / MOV / WebM / MKV 上传 | 可独立验证与使用剪辑，不依赖平台网络 |

工具的「爆款」是**已采集集合内的参考评分**，不是平台官方榜单，也不是全站搜索。筛选和自动化处理的前提是先添加参考链接或 TikTok 账号。平台适配器可能因登录、风控或规则变更失效；错误会保留在任务记录中。

发布后云环境已放行平台域名，网页可返回 HTTP 200；使用系统 CA 信任配置后，TikTok 示例仍被平台限制 IP，用户提供的抖音链接详情接口返回 403 并要求 fresh cookies。**尚未验证从 TikTok / 抖音成功抓取或下载真实视频**。网络开放不保证平台允许匿名访问。云代理证书的设置保存在云环境安装与启动配置中，普通 Windows 本地运行无需复制这项配置。

若平台要求登录，可以在服务器设置 `VIRALLAB_COOKIES_FILE`，指向你有权使用的 Netscape 格式 cookies 文件。不要将 cookies 提交到仓库或粘贴到聊天。无需 GitHub token，也无需 AI key 来下载与剪辑。

## 导入数据

支持 `{ "videos": [...] }` 或直接视频对象数组，最多 100 条。URL 必填；请使用真实视频链接。未知指标省略或填 `null`，界面显示 `—`。

```json
{
  "videos": [
    {
      "url": "https://www.douyin.com/video/替换为真实视频ID",
      "title": "你的参考视频标题",
      "author": "作者",
      "views": 120000,
      "likes": 9000,
      "comments": 700,
      "shares": 1200,
      "duration": 30,
      "published_at": "2026-10-07T00:00:00Z",
      "tags": ["美食"]
    }
  ]
}
```

也兼容 yt-dlp 风格的 `id`、`webpage_url`、`uploader`、`view_count`、`like_count`、`comment_count`、`repost_count`、`timestamp` 等字段。按平台与视频 ID 去重，重复采集更新指标并计算与上次采集相比的播放增量。

## 评分

总分 100：传播规模 45、加权互动率 30、新鲜度 15、播放增长 10。

- 传播规模：`min(1, log10(1 + views) / 7) × 45`。
- 加权互动率：`(likes + 3×comments + 5×shares) / views`，达到 12% 时该项满分。
- 新鲜度：`exp(-发布天数 / 14) × 15`，缺少发布时间则不计该项。
- 播放增长：相比上次采集增长 20% 时该项满分；不同采集间隔的增长值不能直接作为每小时增长对比。

缺失播放量时不计算互动率；缺失点赞、评论、分享不会捏造数据，但会使该项得分偏低。卡片会标记指标不完整。分数用于筛选参考，不构成流量承诺。

## 创作方案（辅助）

「生成方案」可设置主题、受众、表达风格和 15–90 秒时长，输出可编辑口播、分镜与剪辑建议，导出 Markdown、JSON 或 ZIP。

默认是本地模板，**只使用元数据，没有分析原片画面、音频或逐字稿**。分镜预演为无声提示卡视频，不能当作真实二剪成片。下载 / 二剪功能处理的则是原片实际画面。

可选 AI 定制方案，配置：

```bash
# key 在安全的运行环境变量中配置，不要写入代码。
export VIRALLAB_LLM_BASE_URL=https://api.openai.com/v1
export VIRALLAB_LLM_MODEL=gpt-4o-mini
# 安全配置 VIRALLAB_LLM_KEY 后重启服务。
```

接口需兼容 `/chat/completions` 与 JSON response format，使用 HTTPS。AI 未配置时本地模板与下载剪辑都能运行；AI 在线服务在本次环境未验证。

## 数据与重启

SQLite 数据库和媒体位于忽略的 `data/`，可由 `VIRALLAB_DATA_DIR` 调整。六条演示样本与真实数据分开存储，卡片明确标注演示，统计只计真实采集。演示卡片没有平台原片，上传本地视频可以体验剪辑。

服务退出后进程不会随快照恢复，需重新执行启动命令。重启会将中断任务标记为失败；到期采集源会继续调度。数据库、原片和二剪文件保留；当前没有媒体自动清理机制。

## 验证

```bash
cd /workspace/01
.venv/bin/python -m unittest discover -s tests -v
node --check app/static/app.js
```

测试包含本机登录文件的格式与域名过滤、过期登录拒绝、配置恢复和清除、Firefox SQLite fixture 读取、跨站与远程请求拒绝、以及真实 FFmpeg 编码、上传、原片保留、时长与画幅与音轨核对、自动流水线、定时触发、去重、导出、错误结果和输入校验。平台接口在测试中用 fixture 替代；此项不证明平台当前可抓取。

可选浏览器验证（需 Playwright 和 Chromium）：

```bash
python3 tests/browser_smoke.py
```

浏览器测试使用独立临时数据库与 8001 端口，验证本机登录文件导入、状态恢复、清除和错误提示、筛选、方案编辑和 ZIP 下载、本地上传、真实剪辑、MP4 预览与下载、任务列表和移动布局。通过 `CHROMIUM_PATH` 指定 Chromium。
